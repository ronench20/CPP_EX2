# -CPP_EX2
### This project is an implementation of operators in c++.

## compilation
to compile the project, you can use the following command:
```bash
make                #compile the project
make test           #compiles the tests executable and runs the tests
make Main           #runs the main program
make valgrind       #runs valgrind on the main program
make valgrind-test  #runs valgrind on the tests
make clean          #Deletes all .o files

```
## In this project I had to implement the following operators:
- +, -, *, /, %, ++, --, +=, -=, *=, /=, %=, ==, !=, <, >, <=, >=
- 
Those operators are declared in SquareMat.hpp and implemented in SquareMat.cpp.

## The project also includes a test file that tests the operators and a main file that demonstrates the use of the operators.
